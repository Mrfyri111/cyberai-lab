# 🛡️ CyberAI Lab

Интеллектуальная система мониторинга и обнаружения аномалий сетевого трафика.

## Возможности

- **Захват трафика** через TShark (Wireshark) в реальном времени
- **Обнаружение аномалий**: правила (сканирование портов, SYN-flood, ARP-спуфинг,
  ICMP/DNS/ARP-флуд) + машинное обучение **Isolation Forest**
- **Откуда трафик**: сайт (DNS/HTTPS), сервис (YouTube, Steam…), программа на ПК
- **Уровни угроз**: низкий / средний / высокий с объяснением причины
- **AI-ассистент** на Groq (`openai/gpt-oss-120b`)
- **PDF и CSV отчёты**
- **Аккаунты**: регистрация, вход, «Запомнить меня», защита от подбора пароля,
  подтверждение почты кодом, восстановление пароля

## Три источника трафика

| Источник | Что нужно | Для чего |
|---|---|---|
| 📡 **Мой ПК** | Wireshark + Npcap | Живой мониторинг своего компьютера |
| 🎬 **Демо** | ничего | Записанная домашняя сеть с 4 атаками: сканирование портов, всплеск загрузки, ARP-спуфинг, SYN-flood |
| 📂 **Файл** | запись `.pcap` / `.pcapng` | Анализ сохранённого трафика (Wireshark, PCAPdroid на Android) |

Демо и файлы разбираются собственным модулем `pcap_reader.py` — Wireshark для них не нужен,
поэтому они работают и в онлайн-версии. Кнопка **👤 Войти как гость** — попробовать без регистрации.

> Живой захват по ссылке в браузере невозможен в принципе: браузер не даёт сайту
> доступ к сетевой карте. Для мониторинга своего ПК программу запускают локально.

## Технологии

Python 3.13 · Streamlit · TShark · scikit-learn · SQLite · Groq API · ReportLab

## 💻 Скачать для Windows (проще всего)

**[⬇️ CyberAI_Lab.exe](https://github.com/Mrfyri111/cyberai-lab/releases/download/windows-latest/CyberAI_Lab.exe)**
— скачай, запусти, нажми «Да» на вопрос о правах администратора. Откроется браузер
с программой, источник **📡 Мой ПК** → **▶ Старт** — живой мониторинг своей сети.

- Python и Wireshark **не нужны**: трафик пишет встроенная утилита Windows `pktmon`
  (Windows 10 версии 2004+ или Windows 11).
- Права администратора нужны только для записи трафика.
- Данные хранятся в `%LOCALAPPDATA%\CyberAI Lab`.
- Windows может показать «Система Windows защитила ваш компьютер» — программа не подписана:
  «Подробнее» → «Выполнить в любом случае».

`.exe` собирается автоматически на GitHub Actions при каждом изменении кода
(`.github/workflows/build-windows.yml`).

## Запуск из исходников (Windows)

1. Установи [Wireshark](https://www.wireshark.org/download.html) вместе с **Npcap**.
2. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запусти:
   ```
   streamlit run app.py
   ```
4. Зарегистрируйся → ⚙️ Настройки → 📡 Захват трафика →
   **⚡ Найти активный интерфейс** → ▶ Старт.

## Почта (необязательно)

Без настройки работает **демо-режим**: коды подтверждения печатаются в терминале.
Для настоящих писем заполни `.streamlit/secrets.toml`:

```toml
[email]
smtp_server = "smtp.gmail.com"
smtp_port = 465
user = "почта@gmail.com"
password = "пароль приложения"
sender_name = "CyberAI Lab"
```

## Безопасность

- Пароли — хэш PBKDF2 (310 000 итераций), Groq-ключи — шифрование Fernet
- Блокировка после 5 неудачных входов, замедление ответа
- Коды подтверждения: 10 минут, 5 попыток, одноразовые
- Папка `data/` и `secrets.toml` не попадают в репозиторий

> ⚠️ Анализируй только свою сеть. Аномалия — это отклонение от обычного
> поведения, а не доказательство атаки.
